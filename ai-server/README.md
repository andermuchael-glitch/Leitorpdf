# LeitorPDF AI\n\nServidor opcional para a função **Criar imagem com IA**. A chave da OpenAI fica somente no servidor; não deve ser colocada dentro do APK.\n\n## Variáveis\n\n- `OPENAI_API_KEY`: chave da API\n- `OPENAI_IMAGE_MODEL`: padrão `gpt-image-2.5-flare`\n- `AI_API_TOKEN`: token opcional para proteger o endpoint\n\n## Endpoints\n\n- `GET /health`\n- `POST /generate-image` com `{ "prompt": "..." }`\n\nO app envia apenas o texto selecionado e recebe uma imagem PNG em base64.\n
